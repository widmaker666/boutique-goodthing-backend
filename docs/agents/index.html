Agents Encaissly

Sous-agents spécialisés globaux (~/.claude/agents/) — généré et maintenu par le skill agent-factory. Utilisables depuis boutique-backend et encaissly-mobile.

nestjs-expert

sonnet (défaut) opus si refonte archi
Spécialiste backend NestJS — modules, controllers, services, DTOs, guards, decorators, validation.
Quand l'utiliser
  • Créer/modifier un module NestJS (module/controller/service/DTO)
  • Routes, DI, guards (JWT/Roles/Plans)
  • Validation class-validator
  • Architecture backend NestJS
Délégation
  • Schema Prisma / migration / requête complexe → prisma-expert
  • Perf requête Postgres/Neon → neon-postgres-expert
  • Types génériques avancés / config TS → typescript-expert
Audit déclenché si
  • Diff touche auth/, données perso (User/Creatrice), Stripe, tokens/secrets → security-rgpd-expert

prisma-expert

sonnet (défaut) opus si migration risquée
Spécialiste Prisma v7 — schema.prisma, migrations, requêtes, relations, enums.
Quand l'utiliser
  • Modifier schema.prisma
  • Créer/exécuter une migration
  • Écrire/optimiser une requête Prisma (findMany, aggregate, groupBy, transactions)
  • Relations, cascade, enums, client généré
Délégation
  • Intégration service/controller → nestjs-expert
  • Perf requête (index, query plan) → neon-postgres-expert
Audit déclenché si
  • Migration risque perte de données → STOP + validation explicite (hors caveman)
  • Champ ajouté = donnée perso (User/Creatrice) → security-rgpd-expert

neon-postgres-expert

sonnet (défaut) opus si redesign cross-modules
Spécialiste perf PostgreSQL/Neon — index, query plans, pooling, agrégations lourdes.
Quand l'utiliser
  • Requête lente / EXPLAIN ANALYZE
  • Index manquant, N+1, agrégations stats/export
  • Config pooling Neon
Délégation
  • Ajout @@index / migration → prisma-expert
  • Refacto logique service → nestjs-expert
Audit déclenché si
  • $queryRaw/$executeRaw → check injection + security-rgpd-expert si données perso

security-rgpd-expert

opus (défaut)
Audit sécurité applicative + conformité RGPD — auth/JWT, données perso, Stripe/webhooks, guards.
Quand l'utiliser
  • Audit sécu avant merge
  • Ajout/modif champ donnée perso (User/Creatrice)
  • Changement auth/tokens, Stripe/webhook
  • Question conformité RGPD
Délégation
  • Fix nécessite changement schema → prisma-expert
  • Fix nécessite changement service/guard → nestjs-expert
  • N'implémente pas le fix lui-même si hors périmètre — identifie + délègue
Points connus à revérifier
  • CORS origin: '*' dans main.ts
  • console.log avec données sensibles dans vente.service.ts
  • Ordre raw body Stripe webhook avant ValidationPipe
  • Guards Roles/Plans : fail-open si pas de métadonnée

react-native-expert

sonnet (défaut) opus si refonte cross-écrans
Spécialiste React Native/Expo (mobile) — composants, styles, TanStack Query, Zustand, Axios, design system.
Quand l'utiliser
  • Créer/modifier un écran ou composant
  • State Zustand, data fetching TanStack Query
  • Styling, design system, intégration services/api.ts
Délégation
  • Endpoint backend manquant/à modifier → nestjs-expert (+ prisma-expert si schema)
  • Routing/layout/navigation → expo-router-expert
  • Typage complexe → typescript-expert
Audit déclenché si
  • Modif stockage tokens/données perso (Zustand persist, SecureStore, AsyncStorage) → security-rgpd-expert

expo-router-expert

sonnet (défaut) opus si refonte routing globale
Spécialiste Expo Router (mobile) — routing file-based, layouts, navigation, guards d'auth, tabs.
Quand l'utiliser
  • Créer/modifier une route ou écran (app/)
  • Navigation, redirections, layouts (_layout.tsx), tabs
  • Guard d'authentification basé sur Zustand
Délégation
  • Contenu/logique d'écran → react-native-expert
  • Nouvel endpoint backend → nestjs-expert
  • Typage navigation → typescript-expert
Audit déclenché si
  • Modif guard d'auth (app/_layout.tsx, redirections selon token/role/plan) → security-rgpd-expert

typescript-expert

sonnet (défaut) haiku si fix trivial opus si refonte types partagés
Spécialiste TypeScript — types/generics avancés, tsconfig, typage Prisma/NestJS, narrowing.
Quand l'utiliser
  • Erreur TS complexe / typage générique
  • Config tsconfig.json / build
  • Typage des retours Prisma (relations incluses, payloads)
Délégation
  • Payload Prisma incorrect → prisma-expert
  • Type DTO/decorator NestJS → nestjs-expert
Audit déclenché si
  • Type expose champ sensible (password/refreshToken) → security-rgpd-expert
